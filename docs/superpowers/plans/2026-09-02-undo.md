# Undo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `esegnorelli.undo`: Super+Z restores the last closed window or config burst.

**Architecture:** `Model.js` owns the stack, Hyprland event parse, launch command, and the existing config git store. `scripts/undo-hypr` reads socket2 and pushes window items. `scripts/rewind-watch` still records config and also pushes config items. Service exposes IPC `undo`. Bar click = undo. Overlay is history.

**Tech Stack:** QML/Quickshell, Node, Hyprland socket2, git commit-tree.

**Spec:** `docs/superpowers/specs/2026-09-02-undo-design.md`

## Global Constraints

- Plugin id `esegnorelli.undo`, name Undo, MIT
- kinds: service, bar-widget, overlay
- Stack file `~/.local/state/omarchy/undo-stack.json`, cap 50, clear on new boot_id
- Config store stays `~/.local/share/omarchy-rewind/store/`
- Super+Z undo, Super+Shift+Z overlay; do not touch Super+Ctrl+Z zoom
- Bind block marker `-- esegnorelli.undo` in `~/.config/hypr/bindings.lua`
- `node test-model.js` and `omarchy plugin validate .` must pass
- Disable `esegnorelli.rewind` when enabling Undo

## File map

- Modify: `Model.js`, `test-model.js`, `manifest.json`, `Service.qml`, `BarWidget.qml`, `Overlay.qml`, `scripts/rewind-record.js`, `README.md`
