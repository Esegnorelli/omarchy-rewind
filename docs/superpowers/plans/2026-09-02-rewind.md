# Rewind Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `esegnorelli.rewind`, an Omarchy plugin that records config bursts and restores them from a timeline overlay.

**Architecture:** Pure rules in `Model.js` (QML + Node). `scripts/rewind-record` talks to git. `scripts/rewind-watch` debounces inotify. A headless service keeps the watcher alive. Bar widget summons the overlay. Overlay reads `rewind-status.json`.

**Tech Stack:** QML/Quickshell, Node (tests + record), bash (inotifywait), git commit-tree.

**Spec:** `docs/superpowers/specs/2026-09-02-rewind-design.md`

## Global Constraints

- Plugin id `esegnorelli.rewind`, name Rewind, MIT
- kinds: service, bar-widget, overlay; keepLoaded false
- Store at `~/.local/share/omarchy-rewind/store/` with parentless git commits, tags `rewind/<unix-ms>`
- Status at `~/.local/state/omarchy/rewind-status.json`
- Burst gap 12s; skip secrets, `.git/`, files > 256KB, escaped symlinks
- Labels: theme > plugin > agent > you
- Restore writes a belt commit first; reload order is theme refresh, hyprctl reload, rescanPlugins
- Never sudo; never write outside hypr, omarchy config, rewind share, rewind state
- `node test-model.js` and `omarchy plugin validate .` must pass
- README in English
